# Process, instrumentation, piping, HVAC, plumbing and fluid power diagram standards

Research notes for VizCraft notation packs, 2026-10-19. Standard texts are copyright their publishers; only the facts below may be reused, never the artwork. Primary texts read: ANSI/ISA-5.1-2009 (university-hosted copy), ISO preview samples of ISO 10628-1, 10628-2, 14617-7/-8/-9 and 1219-1, and a PIP PIC001 (1998) sample. Not verified before the search budget ran out: ANSI/ASHRAE 134 and SMACNA symbol contents, the module value in ISO 1219-1, and the 2012 wording of the ISO 1219-2 identification code.

**Tables 5.3.1 and 5.3.2 lines.** Instrument-to-process: plain, traced (ET, ST, CW), generic, flanged, threaded, socket-welded, welded. Instrument-to-instrument: supply IA/PA/NS/GS/ES/HS, undefined, pneumatic (slashed), electric (dashed), functional continuous and binary, hydraulic (L), capillary (X), guided electromagnetic/fibre, wireless, DCS/PLC bus, inter-system link, fieldbus, smart-device link. ## 5. Machine-checkable rules per document type

P&ID (ISA-5.1, ISO 10628-1, PIP PIC001): every tag parses as letters + loop number + optional suffix with valid letter positions (unknown letters only if declared user's choice); tags unique across the set; every line number matches the project pattern with service codes from the declared list; sequence changes at branches to other equipment and at PSV inlet/outlet, not at control valves or class breaks; off-page connectors paired by number with reciprocal P&ID references; every nozzle connected or capped; every automated or safety valve tagged; loops complete from primary element through transmitter and controller to final element; relief devices show set pressure and sizes; unconnected crossings interrupted; PFD streams numbered with rates and conditions.

Loop diagram (ISA-5.4): one loop per sheet; all loop tags present; every signal terminates on both sides of each boundary with cable, pair and terminal; channel unique.

HVAC and plumbing: every run has size and airflow or fixture units; terminals and equipment tagged and resolvable to the schedule; dampers typed; risers show backflow devices, pumps and heaters from meter to outlet ([LADBS](https://dbs.lacity.gov/sites/default/files/efs/forms/pc11/supplemental-plumbing-correction-sheet-for-high-rises-pc-mech-corr106.pdf)).

Fluid power (ISO 1219-2): every port connected or plugged; port labels match the valve type's port set; each pressure line traces back to a pump or accumulator and ends at an actuator, tank or plug; every pump has a reservoir or supply; a relief valve downstream of each fixed-displacement pump; codes unique; valves in rest position with rest-square port numbers only; pilot and drain lines dashed; the displacement-step diagram changes only the actuators shown per step.

## Implications for a notation pack (synthesis)

**P&ID pack.** Element types follow ISO 10628-2 groups and the DEXPI taxonomy: Vessel, Tank, Column, HeatExchanger, Pump, Compressor, Blower, Fan, Filter, Separator, Agitator, Furnace, Nozzle; OperatedValve with body kind (Gate/Globe/Ball/Butterfly/Plug/Needle/Check/Safety) and actuator kind; PipeFitting, Reducer, Tee, Strainer, Orifice, RuptureDisc, Flange, LineBlind, PipeOffPageConnector; Instrument bubble with system column and location row. Ports: nozzles as named ports (SubTagName, NominalDiameter, NominalPressure); two or three flow ports on valves and fittings; one process port plus signal ports on instruments. Segment properties per DEXPI: NominalDiameter, PipingClassCode, FluidCode, insulation, tracing, FlowDirection. Connection table: process line joins nozzle, fitting, valve, inline instrument, off-page connector; signal kinds join bubbles, actuators and signal connectors only. Formats: equipment `{class}-{unit}{seq}{suffix}` (P-101A); line `{size}-{service}-{seq}-{class}-{insulation}` with configurable field order; tag `{first}{mod}{succ}-{loop}{suffix}` with a parallel/serial switch. Styles: NC valves filled, widths 0,4/0,2/0,1 M, SIS diamond, panel row line. Validations from section 5, plus DEXPI-shaped export (segment = node-to-node run).

**Instrumentation loop pack.** Types: Instrument (reusing the P&ID tag), JunctionBox, TerminalStrip, Terminal, Cable and Pair, MarshallingCabinet, IOChannel, ControllerFunction, Barrier, PowerSupply. Terminals are numbered ports; a wire joins exactly two, and a wire crossing a lane (Field, JB, Marshalling, Control room, Panel front) lands on a terminal. Formats: cable `{loop}-C{n}`, JB `JB-{area}{n}`, terminal `{strip}:{n}`, channel `{rack}.{slot}.{ch}`. Validations: one loop per sheet, all loop tags present, channel unique, no floating terminal.

**HVAC pack.** Types: AHU, Fan, Coil, Filter, Humidifier, Damper (volume, fire, smoke, backdraft, motorised), Diffuser/Grille, DuctSegment (round or W x H), Fitting, Silencer, VAV/CAV, Sensor, Chiller, Boiler, Pump, Valve, Pipe. Ports: air in/out, water supply/return, control. Properties: airflow, size, material, insulation, pressure class. Formats: `AHU-{n}`, `VAV-{floor}-{n}`. Styles: supply/return/exhaust line styles; double- or single-line duct as a view option. The plumbing riser reuses this pack with Y32.4 fixtures, systems (CW, HW, HWR, SAN, VENT) and fixture-unit sums.

**Fluid power pack.** Model ISO 1219 symbols as parameterised glyphs. A DirectionalValve glyph takes positions (2 or 3, optional crossover), ports (2 to 5), a per-position path table (port pairs: through, blocked, bidirectional), actuation per side (lever, button, pedal, roller, plunger, solenoid, pneumatic or hydraulic pilot, combined), return (spring, detent, none), rest position index and port label set (P T A B X Y L or 1 2 3 4 5 12 14). The renderer lays squares on the module grid, draws paths from the table, places actuators outside the end squares and labels ports only on the rest square. The same scheme covers pumps and motors (triangle count and direction, variable arrow, drain), cylinders (acting, rod sides, cushioning, spring return), pressure valves (relief, reducing, sequence: one square, pilot source, spring, adjustability) and accessories. ISO 1219-3 stacking becomes a snap rule on shared port edges. Properties: nominal pressure, flow, displacement, medium (filled triangle hydraulic, hollow pneumatic). Format per ISO 1219-2: `{installation}{circuit}{letter}{seq}`, letter optional for the 2012 form, circuit 0 the power unit. Connection table: working line joins any port; pilot line joins pilot ports; drain joins L ports to tank; mechanical link joins rod to roller or switch; electrical signal joins solenoid to control. Validations from section 5, plus a displacement-step chart whose transitions must be reachable from the valve path tables.

Common to all packs: a provenance field per glyph ("drawn from ISO 14617 registration 2111 description" or "own design"), a per-pack module M scaling line widths, and an export mapping to DEXPI class names and RDL URIs.
